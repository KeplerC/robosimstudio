# Bench tasks

<!-- written by scripts/gallery.py from gallery/index.toml; edit the manifest, not this page -->

Contact-rich bench tasks with deformable materials: wiping, polishing, tape and film peeling, cutting carton tape and threading a cable through a conduit. Ported to current main on the YAM, where the robot moves things only by finger contact, and re-filmed path traced in November 2026.

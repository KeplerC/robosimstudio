# RGBS bench videos

<!-- written by scripts/gallery.py from gallery/index.toml; edit the manifest, not this page -->

Five real two-arm bench chores from the RGBS robot videos (cable routing, box decanting, filing, protector film peeling and surface preparing), each rebuilt in RoboSimStudio by a coding agent on the live page from its clip, and accepted by a reviewer agent that judged it against the clip. The robot is the catalog YAM and moves things only by finger contact. The real videos are not published here: every clip is the simulation. One bench task with no video, the tape-strip peel, runs on the older benchmark code in tasks/.

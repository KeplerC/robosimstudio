# ABC-130k twins

<!-- written by scripts/gallery.py from gallery/index.toml; edit the manifest, not this page -->

Twins of real teleoperated episodes from the [ABC-130k](https://huggingface.co/datasets/XDOF/ABC-130k) dataset (XDOF), built by a coding agent on the dataset's own YAM station and checked by a reviewer agent. Each clip is the simulation, replaying the recorded episode on the twin.
